# ✦ Laye Anime 2026 ✦

> Une galerie d'animes interactive, moderne et personnalisable pour les passionnés.

Laye Anime 2026 est une application web élégante permettant de gérer sa collection d'animes, de suivre sa progression et de visualiser ses statistiques de visionnage. Le projet inclut également un tableau de bord de surveillance des performances système (PC Monitor).

## 🚀 Fonctionnalités

### 🎬 Galerie d'Animes
- **Gestion de Collection** : Ajoutez vos propres animes ou supprimez ceux existants.
- **Suivi de Progression** : Gérez le nombre d'épisodes vus via une interface intuitive.
- **Système de Favoris** : Marquez vos coups de cœur et filtrez votre galerie instantanément.
- **Recherche & Filtres** : Recherche dynamique par titre, année de sortie ou genre (Shōnen, Shōjo, Isekai, Mecha).
- **Partage Social** : Générez des cartes de partage personnalisées ou des QR Codes pour mobile.
- **Statistiques** : Visualisez la répartition de vos genres préférés via des graphiques circulaires.

### 🛠️ Personnalisation & UI
- **Mode Sombre / Clair** : Basculez entre deux thèmes visuels optimisés.
- **Réglages Avancés** : Modifiez la taille des cartes, activez/désactivez les animations et les effets sonores.
- **Profil Utilisateur** : Personnalisez votre nom, votre email et votre photo de profil (sauvegardés localement).

### 🖥️ PC Monitor
- Un tableau de bord futuriste (style cyberpunk) pour surveiller en temps réel l'utilisation du CPU, de la RAM et du GPU.
- Détection automatique des anomalies et journal des événements.

## 🛠️ Technologies Utilisées

- **Frontend** : HTML5, CSS3 (Variables, Flexbox, Grid), JavaScript (ES6+).
- **Graphiques** : [Chart.js](https://www.chartjs.org/) pour les statistiques.
- **Icônes** : [Tabler Icons](https://tabler-icons.io/).
- **Utilitaires** : [QRCode.js](https://davidshimjs.github.io/qrcodejs/) pour la génération de codes mobiles.
- **Stockage** : `localStorage` pour la persistance des données sans base de données externe.

## 📦 Installation

1. Clonez le dépôt :
   ```bash
   git clone https://github.com/votre-pseudo/laye-anime-2026.git
   ```
2. Ouvrez le dossier du projet :
   ```bash
   cd laye-anime-2026
   ```
3. Lancez le fichier principal dans votre navigateur :
   ```bash
   # Sous Windows
   start index.html
   ```
